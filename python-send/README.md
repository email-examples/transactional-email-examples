# Python + urllib

Stdlib-only send. No third-party SDK.

## Setup

```bash
export NOTIFY_API_KEY=nk_your_key_here
# or: set -a; source .env; set +a
```

## Sandbox

```bash
NOTIFY_SANDBOX=1 python3 send.py
```

## Production

```bash
python3 send.py
```
